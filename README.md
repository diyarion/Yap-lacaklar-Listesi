# Yap-lacaklar-Listesi
# 📝 Yapılacaklar (Todo) Uygulaması

Bu proje, günlük görevlerinizi pratik bir şekilde ekleyebileceğiniz, tek tek silebileceğiniz veya tüm listeyi tek seferde temizleyebileceğiniz dinamik bir **Todo Web Uygulamasıdır**. 

JavaScript'te dizi metotları (`splice`, `findIndex`), DOM manipülasyonu ve dinamik eleman yönetimi pratikleri yapmak amacıyla geliştirilmiştir.

## 🚀 Özellikler
- **Görev Ekleme:** Giriş alanına yazılan görevleri listeye dinamik olarak ekler.
- **Tekli Silme:** Her görevin yanındaki sil butonu ile sadece seçilen görevi kaldırır.
- **Tümünü Temizle:** Tek bir butonla listedeki tüm görevleri sıfırlar.

## 🛠️ Kullanılan Teknolojiler
- HTML5
- CSS3
- Modern JavaScript (ES6+)
